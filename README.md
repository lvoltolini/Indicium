# 📊 Previsão de Preços de aluguel de Imóveis

Exploração, preparação e modelo de regressão linear para explicar preços de aluguel imóveis. 

A análise inclui tratamento de dados, seleção de variáveis com LASSO, detecção de multicolinearidade e ajustes no modelo de regressão.

```bash
git clone https://github.com/lvoltolini/LH_CD_VOLTOLINI
cd Indicium
```

### 2️⃣ Criar um Ambiente Virtual

```bash
source venv/vin/activate
```
